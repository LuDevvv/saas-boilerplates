# Node Stack — Architecture Whitepaper

Author: Ludevv
Last updated: April 2026

## Executive Summary

The **Node Stack** is a production-grade, ultra-resilient SaaS foundation built on **NestJS**, **Drizzle ORM**, and **PostgreSQL**. It is designed to solve the common challenges of modern SaaS development: multi-tenant isolation, transactional integrity, and background process resilience. By utilizing a monorepo structure and shared technical standards, it enables rapid scaling from a single-tenant prototype to a globally distributed platform.

## 1. System Philosophy

The architecture prioritizes **Correctness** and **Predictability**. It achieves this through:
- **Zero-Trust Multi-tenancy**: No cross-tenant leakage by design using Guards, AsyncLocalStorage, and RLS.
- **Reliable Side Effects**: The Outbox Pattern ensures that external systems (emails, webhooks, billing) are always in sync with the database.
- **Modern DX**: Strict TypeScript, Zod-driven validation, and autogenerated OpenAPI documentation.

## 2. Technical Stack

- **Framework**: NestJS v11 (latest)
- **Runtime**: Node.js v20+ (LTS)
- **Database**: PostgreSQL with **Drizzle ORM** (SQL-first, Type-safe)
- **Caching & Queues**: Redis + **BullMQ**
- **Validation**: **Zod** (Single source of truth for DTOs and database)
- **Communication**: REST + WebSockets (Socket.io)
- **Observability**: Pino (Structured Logging), OpenTelemetry (Tracing), Sentry (Errors)

## 3. Core Modules

### 🔐 Authentication & Identity
- Supports **JWT Bearer Auth** (interactive) and **API Keys** (programmatic).
- Native 2FA (TOTP) and OAuth2 (Google/GitHub) support.
- Session management with rotation and revocation.

### 📂 Workspace & RBAC
- Granular Role-Based Access Control (RBAC) with hierarchical permissions.
- Member invitation workflows with secure tokens.
- Strict isolation enforced at the service and database layers.

### 💳 Billing & Monetization
- **Polar.sh** first-class integration for modern SaaS billing.
- Support for multiple plans, usage-based billing, and idempotent checkout.
- Automated webhook handling and subscription lifecycle management.

### 📁 Storage & Assets
- Context-aware storage policies (size, mime-types).
- Secure S3-compatible storage integration (MinIO, R2, AWS).
- Presigned URL workflow for direct client uploads.

## 4. Operational Excellence

- **Migrations**: Automated via `drizzle-kit` during deployment.
- **Performance**: Sub-50ms overhead for internal framework logic; horizontal scalability for API and Worker nodes.
- **Security**: Strict CSP, Helmet, Rate Limiting (Redis), and Idempotency keys for all write operations.

## 5. Roadmap & Future Direction

The Node Stack is evolving towards:
- **Native AI Adapters**: Deeper integration with LLM providers for agentic workflows.
- **Edge Compatibility**: Optimized core modules for deployment on Edge runtimes.
- **Advanced Portability**: Built-in tools for GDPR-compliant data export/import per workspace.
