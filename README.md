# 📚 SaaS Boilerplates Collection

A collection of elite, production-ready boilerplates for various runtimes and architectures.

## 📁 Projects

### 🌊 [Edge Stack](./edge/edge-stack)
**Runtime**: Cloudflare Workers (Edge V8)
**Stack**: Hono, Astro, Drizzle, Neon.
*Optimized for sub-50ms global latency and minimal cost.*

### 🚀 [Node Stack](./node/node-stack)
**Runtime**: Node.js (Containers/VPS)
**Stack**: NestJS, Drizzle, Redis, BullMQ.
*Optimized for high-performance, background heavy, and complex transactional systems.*

---

## 🛠️ Repository Management

This repository uses a sub-folder structure to separate different boilerplate philosophies.

- **`edge/`**: Projects optimized for Serverless Edge runtimes.
- **`node/`**: Projects optimized for traditional VPS/Container runtimes.
